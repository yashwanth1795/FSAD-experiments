# FSAD Experiment 11

React API Integration Workbook

## Run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

## Pages

- Local Users: fetch from `public/users.json`
- Users API: fetch from `https://jsonplaceholder.typicode.com/users`
- Fake API Posts: axios request to `https://dummyjson.com/posts`
